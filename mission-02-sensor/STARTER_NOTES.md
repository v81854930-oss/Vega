# Starter notes

The repository gives you a starting point rather than a completed solution.

Use the official Bosch documentation and BMP280 datasheet when you need details about the sensor.

You do not need to buy hardware for this challenge. If you have an ESP32, Arduino, Raspberry Pi, or another suitable board and a BMP280, you can test the setup physically. Otherwise, a connection diagram and working code are enough.

You may use a sensor library. Do not spend the whole challenge trying to write a driver from scratch.

A good first milestone is simple: understand the pins, understand the interface, get a reading, and be able to explain how you know the reading is plausible.
