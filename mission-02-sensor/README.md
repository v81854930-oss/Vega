# VEGA-01 — Mission 02

## Bring a Sensor to Life

This folder contains the second avionics recruitment challenge for Team VITAKSH.

Start with `task.md`.

The challenge uses the **BMP280** as the example sensor. Candidates may use physical hardware if they have it, but hardware is not required to complete the task.

For sensor details, use the official Bosch BMP280 documentation and datasheet.
