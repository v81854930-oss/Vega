# Screening Submission

Keep your work organised by mission:

```text
submission/
├── mission-01/
└── mission-02/
```

Please include your final work, screenshots where useful, source/configuration files where applicable, a short README for each mission, and a note explaining anything unfinished.

## Document these things

### What did you assume?

### What did you try?

### How did you test it?

### What did not work on the first attempt?

### What would you improve?

A short honest explanation is more useful than pretending everything was perfect.
