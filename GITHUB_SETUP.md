# GitHub setup

GitHub is optional for taking part in the recruitment challenge.

If you already use GitHub, you can make your own copy of the repository and keep your work there.

If you are new to GitHub, you can simply download the challenge files and work locally.

If you decide to use GitHub:

1. Create a GitHub account.
2. Make your own copy of the repository.
3. Work in your own repository.
4. Commit your changes as you work.
5. Submit the repository link when you are ready.

You are not being graded on having an impressive commit history. Keep the repository clean enough that another person can follow what you did.

If you do not have a GitHub account, contact the team when you are ready to submit and we will tell you how to send your work.
